Privacidad

FinClaro está desarrollando un asistente de WhatsApp. Este aviso explica qué datos se usan durante las pruebas del sitio web y del asistente.

Quién trata los datos

Responsable: Alex Muñoz Castellano, titular del proyecto FinClaro.

Contacto: hola@finclaro.es.

Datos del asistente de WhatsApp

Si participas en las pruebas del asistente, FinClaro trata el número o identificador de WhatsApp, los mensajes que envías, el estado de tu consentimiento y los datos que incluyas en solicitudes de agenda y recordatorios, como títulos, fechas, horas, ubicaciones y notas.

Usamos esos datos para recibir tus instrucciones, responderte y gestionar las funciones que solicites. Para activar el servicio envías ACEPTO. Antes de la activación, el sistema revisa el número o identificador y el mensaje entrante para detectar ese comando y descartar remitentes no autorizados. Tras el alta, puedes pedir que deje de atenderte enviando BAJA.

El texto de tus mensajes puede enviarse a OpenAI para interpretar la solicitud y generar una respuesta. Meta proporciona WhatsApp Business Platform y Railway aloja el servicio y su base de datos. No envíes contraseñas, números de tarjeta, claves bancarias ni otra información que no sea necesaria para la prueba.

Conservación

El servicio elimina el texto de la cola de mensajes al procesarlo. El número vinculado, el estado del consentimiento y los datos de agenda y recordatorios pueden permanecer en la base de datos. En este momento no hay un plazo automático de borrado configurado. Para solicitar acceso o eliminación, escribe a hola@finclaro.es.

Base del tratamiento y tus derechos

El uso de las funciones del asistente se activa mediante el consentimiento que expresas al enviar ACEPTO y se limita a las funciones que solicitas. Puedes retirar el consentimiento enviando BAJA y solicitar acceso, rectificación, eliminación, limitación u otros derechos aplicables escribiendo a hola@finclaro.es. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD).

Proveedores

Para prestar el servicio se utilizan WhatsApp Business Platform de Meta, alojamiento y base de datos de Railway y la API de OpenAI para interpretar mensajes. Estos proveedores pueden tratar datos desde distintos países. Cuando haya una transferencia internacional, se aplicarán las garantías previstas en las condiciones de protección de datos de cada proveedor. Puedes solicitar información sobre las garantías aplicables a esta prueba escribiendo a hola@finclaro.es.

Cookies del sitio web

El sitio web carga Google Analytics 4 para medir visitas y Google AdSense para gestionar o medir publicidad. Estos servicios pueden utilizar cookies, identificadores u otras tecnologías. Consulta cómo usa Google los datos y su política de privacidad. También puedes consultar la información de AdSense sobre cookies, gestionar la personalización en Mi centro de anuncios o instalar el complemento de inhabilitación de Google Analytics.
